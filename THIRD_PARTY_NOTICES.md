# Datta Able Free Angular

Este projeto usa a base Datta Able Free Angular Admin Template, da CodedThemes.

- Fonte: https://github.com/codedthemes/datta-able-free-angular-admin-template
- Licença: MIT, preservada integralmente no arquivo LICENSE.
- Personalizações: identidade Rituals, tema escuro, módulos operacionais e simulação local de dados.

Os componentes de card, os estilos base, o Bootstrap e os ícones Feather do template foram mantidos. Não foram utilizados recursos da edição Pro.
